Comment lancer l'application

Suivez ces étapes pour démarrer le serveur Django.

1

Naviguer vers le dossier du projet

cd franchise_invest_ai
2

Installer Django (si pas déjà fait)

pip install django
3

Lancer le serveur

python manage.py runserver
4

Ouvrir dans le navigateur

Accédez à http://127.0.0.1:8000/

Compte administrateur

Username: admin
Password: admin123
Admin panel: /admin/
